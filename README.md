# 치지직 스트리머 리포트

스트리머 채널 링크를 붙여 넣으면 그 순간부터, 방송 중일 때 1분마다 시청자 수·카테고리·채팅 수·치즈 후원 금액을 기록하고 일간/주간 리포트로 보여줍니다.

## 파일

| 파일 | 역할 |
|---|---|
| `app.py` | 수집기와 서버 (방송 중 데이터를 모으고 화면을 제공) |
| `dashboard.html` | 링크를 붙여 넣고 데이터를 보는 화면 |
| `Dockerfile` | Coolify 같은 서버에서 실행하는 설정 |
| `requirements.txt` | 필요한 Python 패키지 |

## Coolify에 올리기

1. 이 파일들을 GitHub 비공개 저장소의 **맨 위(루트)**에 올립니다. 폴더 안에 넣지 마세요.
2. Coolify에서 새 리소스를 만들고 이 저장소를 연결합니다. 빌드 방식은 **Dockerfile**로 선택합니다.
3. 환경 변수를 넣습니다.
   - `APP_PASSWORD`: 직접 정한 비밀번호 (필수. 없으면 시작되지 않습니다.)
   - `PORT`: `8000`
4. **Ports Exposes**를 `8000`으로 맞추고, 쓸 주소(도메인)를 지정합니다.
5. **Persistent Storage**에 볼륨을 추가하고 마운트 경로를 `/data`로 합니다. 빠뜨리면 다시 배포할 때마다 기록이 사라집니다.
6. 배포한 뒤 주소를 열고 로그인합니다. 사용자 이름은 아무거나, 비밀번호는 `APP_PASSWORD` 값입니다.
7. 위쪽 입력칸에 치지직 채널 링크를 붙여 넣으면 그 순간부터 추적이 시작됩니다.

실행 중인 컨테이너는 **1개만** 유지하세요. 2개 이상이면 같은 방송이 중복 기록됩니다.

## 처음 한 번 꼭 점검

Coolify의 컨테이너 터미널에서 **방송 중인 채널**로 실행합니다.

```
python app.py --test 채널링크
```

방송 상태, 시청자 수, 카테고리가 나오고, 30초 동안 읽은 채팅 수와 치즈 후원 합계가 출력되면 정상입니다. 조회가 실패하면 서버 위치나 접속 차단 때문일 수 있으니 출력된 내용을 알려 주세요.

## 알아둘 점

- 링크를 등록한 시점부터 쌓이고, 과거 방송은 가져오지 않습니다.
- 치즈는 채팅창에 표시된 후원 금액의 합계라서 스트리머 실수령액과 다를 수 있습니다. 처음에는 스튜디오 수치와 비교해 보세요.
- 서버가 꺼져 있거나 재배포 중인 시간은 기록되지 않습니다.
- 전체 기록은 `주소/api/export.csv`로 내려받을 수 있습니다.
- 치지직의 비공식 접속 방식을 쓰기 때문에, 치지직 쪽 변경으로 어느 날 읽히지 않을 수 있습니다.
